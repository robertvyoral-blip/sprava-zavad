# Správa závad

Mobilní webová aplikace pro evidenci závad v městských bytech a přípravu hlášení pro příslušného řemeslníka.

## Aktuální verze

- výběr domu a bytu;
- volba druhu závady;
- přiřazení řemeslníka;
- náhled hlášení a otevření e-mailu;
- místní historie závad a změna stavu;
- katalog spravovaných objektů, technologií a servisních firem;
- místní doplnění neveřejných kontaktů bez uložení do GitHubu;
- záloha a obnovení dat ve formátu JSON;
- export závad do CSV;
- instalace na plochu telefonu jako PWA;
- základní fungování bez připojení.

Soukromé údaje a kontakty se ukládají pouze do prohlížeče daného zařízení. Veřejný zdrojový kód obsahuje jen neosobní katalogové údaje.
